# AION Timetable Overlay

Прозрачный оверлей для Windows для приватного сервера AION 4.6 **OriginAion**, остающийся на экране во время игры: расписание PvP Instances / Arenas / Raid / Rifts (время сервера и локальное время, фильтр по уровню, 8 языков), а также командное отслеживание убийств/возрождения для 23 мировых боссов/хранителей ключей (Dabra, Zumita и ещё 21 в Heiron, Tiamaranta, Inggison, Gelkmaros, Reshanta, Sarpan, Eltnen) с общими комментариями.

## Архитектура

Монорепозиторий (pnpm workspaces):

```
apps/
  overlay/    Tauri v2 (Rust) + React/TypeScript – приложение-оверлей для Windows
  backend/    Fastify + Drizzle/SQLite + Playwright – API, WebSocket, скрапер
packages/
  shared/     Общие типы TypeScript между backend и overlay
```

- **Источник данных расписания:** Скрапер на Playwright периодически считывает недельное представление `originaion.com/schedule` (включая текущий часовой пояс сервера) и сохраняет его в backend. Вкладки на этой странице реализованы полностью на стороне клиента, поэтому нужен настоящий headless-браузер, а не простой HTTP-запрос.
- **Модель команды:** Классического логина нет. Один человек создаёт команду (название, описание, пароль) и получает код приглашения; остальные участники присоединяются по этому коду, указывая отображаемое имя. Убийства и комментарии изолированы по командам (`teamId`); владелец команды может позже переименовывать участников.
- **Автономный режим vs. командный режим:** Без присоединения к команде приложение показывает только публичное расписание (`GET /schedule`, вход не требуется). Присоединение к команде добавляет живые комментарии и панель мировых боссов через WebSocket.
- **Фильтр по уровню:** Инстансы dredgion/arena имеют требования к уровню. Подтверждено для originaion.com: Engulfed Ophidan Bridge, Iron Wall Warfront, Kamar Battlefield и Arena of Glory (файтинг 4 на 4, только высший бракет) доступны только в эндгейме (61–65); Terath Dredgion, Arena of Chaos (файтинг 10 на 10), Arena of Discipline (1v1) и Arena of Harmony (3v3) же встают в один из четырёх 5-уровневых бракетов (46–50/51–55/56–60/61–65) — при этом Terath Dredgion запускается под разными названиями в зависимости от бракета — и поэтому доступны во всём диапазоне 46–65. Приложение полностью скрывает инстансы, не соответствующие уровню, указанному в настройках.

## Требования

- **Node.js** ≥ 20 и **pnpm** (`corepack enable && corepack prepare pnpm --activate`)
- **Дополнительно для сборки оверлея (только Windows, целевая платформа):**
  - Rust (`rustup`, стандартная цепочка инструментов `stable-x86_64-pc-windows-msvc`)
  - Microsoft Visual Studio Build Tools с компонентом *Desktop development with C++* (предоставляет линкер MSVC, необходимый Rust в Windows)
  - WebView2 Runtime (уже предустановлен в актуальных версиях Windows 10/11)
- **Для работы backend:** компилятор C (`build-essential` в Debian/Ubuntu) для сборки `better-sqlite3`, а также системные зависимости Chromium, необходимые Playwright (`pnpm exec playwright install-deps chromium`)

> Примечание: приложение-оверлей должно работать как нативная программа Windows (прозрачность и глобальные горячие клавиши над игрой в полноэкранном режиме не работают из WSL/Linux). Разработка backend прекрасно работает под WSL/Linux; для `pnpm tauri dev`/`build` требуется нативная среда Windows с Node + Rust.

## Установка

```bash
pnpm install
```

### Backend

```bash
cd apps/backend
cp .env.example .env        # установите JWT_SECRET в длинное случайное значение
pnpm exec drizzle-kit generate
pnpm run db:migrate
pnpm run db:seed             # заполняет типы/локации мировых боссов + требования к уровню
pnpm run dev                 # запускает API (порт 3000) + cron скрапера
```

Основные эндпоинты:
- `GET /schedule` – публичный, возвращает недельное расписание + смещение часового пояса сервера
- `POST /teams`, `POST /teams/join` – создать команду/присоединиться к команде
- `GET /world-bosses`, `POST /world-bosses/:locationId/kill` – требуется авторизация
- `GET /comments`, `POST /comments` – требуется авторизация
- `WS /ws?token=...` – живые обновления убийств/комментариев/обновления расписания

### Приложение-оверлей (Windows)

```bash
cd apps/overlay
pnpm install
pnpm tauri dev      # разработка с горячей перезагрузкой
pnpm tauri build    # продакшн-сборка (установщик NSIS, см. tauri.conf.json)
```

URL backend сейчас жёстко задан в `apps/overlay/src/config.ts` как `https://timetable.skeeve.tv`.

## Глобальные горячие клавиши

Работают в рамках всей системы (даже когда фокус на игре), пока AION запущен в **оконном режиме или режиме без рамки** – ни один оверлей не может отображаться над эксклюзивным полноэкранным режимом (ограничение DWM, затрагивающее все инструменты оверлея).

| Клавиша | Функция |
|---|---|
| `Ctrl+Shift+O` | Переключить интерактивный режим/режим перемещения (окно становится кликабельным/перемещаемым, становятся доступны мастер команды и панель мировых боссов) |
| `Ctrl+F10` | Переключить панель настроек (размер шрифта, цвет текста, собственный уровень) |

Оба режима временно отключают "проходящие" клики; вне этих режимов окно полностью прозрачно для кликов и никогда не мешает обычному вводу в игре/на рабочем столе.

Поскольку окно намеренно не имеет заголовка/кнопки закрытия, также предусмотрен **значок в трее** ("AION Timetable Overlay") с контекстным меню по правому клику для «Настройки» и «Выход».

## Другое поведение

- **Первый запуск:** При самом первом запуске приложение автоматически открывается в интерактивном режиме + режиме настроек, чтобы новые пользователи могли сразу расположить и настроить его, ещё не зная горячих клавиш.
- **Сброс:** Все настройки (уровень, цвет, принадлежность к команде, статус первого запуска) хранятся в виде JSON-файлов в каталоге данных приложения Tauri (`settings.json`, `auth.json`). Удаление этих файлов полностью сбрасывает приложение.
- **Автозавершение:** Приложение отслеживает процесс клиента AION (`aion.bin`). Как только клиент был замечен запущенным, а затем закрылся, приложение-оверлей также автоматически завершается.
- **Автообновление:** При каждом запуске приложение незаметно проверяет последний GitHub Release, скачивает и устанавливает обновление, если оно доступно, а затем перезапускается - без диалогов и лишних кликов.

## Развёртывание на сервере (справочно)

Сейчас работает в продакшене на `timetable.skeeve.tv`: Node.js + служба systemd (без Docker), SQLite локально на сервере, nginx как TLS reverse-proxy (включая обновление WebSocket для `/ws`), сертификат через certbot. Скрапер запускается ежечасно как часть процесса backend (`node-cron`).

Каталог на сервере (`/opt/timetable`) — это обычный git-чекаут данного репозитория. Обновления проходят через два скрипта в [`deploy/`](deploy/):
- [`deploy/timetable_install`](deploy/timetable_install) – стабильный bootstrap-скрипт, забирает текущую ветку `main`, а затем запускает `install-backend.sh` как новый процесс (сознательно отделён, чтобы работающий скрипт не перезаписывал сам себя в процессе выполнения через `git reset --hard`).
- [`deploy/install-backend.sh`](deploy/install-backend.sh) – устанавливает зависимости backend, применяет отложенные миграции БД, обновляет unit systemd ([`deploy/aion-timetable-backend.service`](deploy/aion-timetable-backend.service)) и перезапускает службу.

Одноразовая настройка (от root на сервере) – сознательно **скопировано, а не сделано симлинком**, чтобы bootstrap-скрипт оставался стабильным даже во время самообновления через git:

```bash
cp /opt/timetable/deploy/timetable_install /usr/local/bin/timetable_install
chmod +x /usr/local/bin/timetable_install
```

После этого для каждого обновления достаточно:

```bash
timetable_install
```

Если сам `deploy/timetable_install` когда-нибудь изменится, повторите шаг `cp` выше один раз.

## Релизы

Push тега вида `v0.1.0` (или запуск workflow вручную во вкладке Actions) запускает [`.github/workflows/release.yml`](.github/workflows/release.yml), который собирает установщик для Windows и публикует GitHub Release с:
- `AION-Timetable-Overlay_x.y.z_x64-setup.exe` – установщик NSIS
- `latest.json` – подписанный манифест, по которому встроенный обновлятор приложения проверяет наличие обновлений

Требует однократной настройки секретов репозитория `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` (Settings → Secrets and variables → Actions).

```bash
git tag v0.1.0
git push origin v0.1.0
```

## Качество данных о мировых боссах

23 мировых босса/хранителя ключей имеют разные уровни достоверности (см. комментарии в `apps/backend/src/db/seed.ts`):
- **Dabra/Zumita:** окно возрождения указано непосредственно пользователем (наивысшая достоверность для этого приложения).
- **16 мировых боссов** (Heiron/Tiamaranta/Inggison/Gelkmaros/Reshanta/Sarpan/Eltnen): времена возрождения из open-source эмулятора `beyond-aion/aion-server` (извлечены из игровых данных, средне-высокая достоверность, не официальный источник).
- **Medeus the Vile, Moltenus, Governor/Berserker/Commander Sunayaka:** не следуют настоящему циклу убийство→возрождение (ночное или еженедельное запланированное окно) – в трекере убийств приближённо представлены как окно примерно в ~1 день/~1 неделю, более низкая достоверность.

Сознательно исключены: Isbariya the Resolute, Hyperion и Queen Modor (все 4 варианта) являются боссами инстансов с еженедельным ограничением входов, а не спавнами в открытом мире. «Kordac» и «Dragon Lord's Champion» были тщательно проверены и не существуют под каким-либо написанием в AION – сознательно не добавлены, вместо того чтобы придумывать данные.

## Открытые вопросы

- Требования к уровню для dredgion всё ещё взяты с другого сервера 4.6 (значения арен уже напрямую подтверждены для originaion.com) и должны быть окончательно проверены на реальном сервере, когда он снова будет онлайн.
- Теперь у всех мировых боссов есть настоящие кликабельные маркеры на карте (Heiron, Inggison, Gelkmaros, Reshanta, Sarpan, Tiamaranta, Tiamaranta's Eye, Eltnen); координаты и изображения карт взяты с aioncodex.com; только для Commander Sunayaka карточных данных нет, и он пока использует только выбор из списка.
- 21 новый мировой босс пока не переведён на все 8 языков (используется английское название как запасной вариант).
